# Vaelitte 的个人分支

本分支基于上游 v0.3.1。以下差异由仓库使用者在 2026-10-19 明确要求，属于个人使用偏好，不代表官方规则或上游项目的行为。

- 部署干员、装备和召唤物时不自动收起商店或缩放镜头。手动收起商店、敌方情报及战场视角切换保留。旧浏览器资料里保存的自动收起设置不再生效，设置页移除该开关。
- 准备阶段单击队友头像直接查看其阵地；战斗阶段单击直接观战。点击自己头像返回自己的战场。连续双击不重复提交同一查看请求。
- 自己的战斗尚未结束时也可观战其他队友，包括另一组的首领战。观战只改变显示目标，自己的权威战斗模拟在后台继续，观战副本不提交结果。
- 观战期间刷新／重连时，服务器先恢复自己的权威模拟，再恢复观战画面。

## 2026-10-20：素材恢复与完整调配文件

- 素材传输共用最多 4 个请求的队列；每次传输超时 45 秒，网络错误、408／429／5xx 最多重试两次，真实 404／403 不反复请求。地图数据使用原有内容哈希缓存，不额外加随机参数。
- 图片失败缓存 15 秒后可重新加载；可选素材清单、二维地图和三维场景失败不再整页永久记住。地图有界补载，恢复网络／切回标签页时继续尝试。干员模型并发从 6 降至 3，超时从 20 秒延长到 60 秒。
- 干员调配的导出文件新增可选 `diy` 字段，包含四个自选位及其干员、技能和模组；潜能／练度继续使用 `ops`。仅选择自选干员也能导出。导入旧文件保留现有自选位；明确的空自选列表可清空；全部不可用的非空列表不会覆盖已保存配置。
- 已核对本机素材清单引用的 30,944 个文件均存在。7 项真实浏览器回归验证了从完整调配导出到全新浏览器导入、刷新后保留自选位及潜能／练度；178 项相关单元／渲染测试通过。网络恢复测试包含限流、瞬断、超时、失败缓存过期。主项目已有环境相关全量测试限制见下文。

这些改动在同学结束当前对局后刷新页面生效，无需清空浏览器数据。随机隧道的公网线路仍可能波动；代码能恢复暂时失败，不能保证第三方线路始终可用。

## 源码与部署

`personal` 是个人修改分支；`upstream` 指向 sganggs/Stronghold-Protocol，`origin` 指向 Vaelitte/Stronghold-Protocol。保留上游历史，后续可以把上游的新版本合并进 personal 并解决冲突。不要用上游整合包直接覆盖个人修改。

本机源码、运行程序、依赖和测试位于 `D:\Stronghold-protocol\source`，个人版使用本机 3001 端口；相邻的 `Stronghold-Protocol` 保留原版及素材。个人版通过本机目录联接共用素材，避免重复占用空间。游戏素材、浏览器资料、日志、下载缓存、隧道令牌不提交 GitHub。修改源码或合并更新后，在对局结束时重启个人版，让服务器与浏览器代码保持一致。

固定公网入口使用本机部署工具中的 ngrok 配置，需用户自己的免费账号与账号分配的域名。它不属于游戏源码，也不将账号令牌写进仓库。固定网址后，同一个浏览器的干员配置、设置和素材缓存可以继续使用；清理浏览器资料、换浏览器或素材发生更新时仍可能重新加载。

## 玩家档案、离线素材与全队作战统计（2026-10-20）

首页与设置的「玩家档案与通行证」显示自动保存状态。登录后，干员调配（含潜能／练度）、持有、自选编队、皮肤选择及对局记录同步到服主 D 盘 `.runtime/private/player-profiles/`。头像后的总览、盟约与策略、战斗累计、对局记录都由恢复的记录计算。身份凭据经过哈希后作为文件名，不在网址、公开接口或仓库中公开。已有本浏览器资料在首次启用时迁移；尚未备份且旧网址已失效的资料不能凭昵称找回。

首次保存成功后，点击「导出玩家通行证」，将 JSON 保存在自己的电脑。换随机网址或浏览器时，关闭旧游戏页面，在新首页导入同一文件，再进入游戏：玩家 ID 保持相同，恢复的是服务器上最新档案，因此不必每局重新导出。每个玩家保存自己的通行证，勿向同学发送这份身份文件。服务器重启、会话过期后仍可恢复 ID；同时使用同一身份的两个页面会触发现有的防抢占保护。正在同盟中不能切换通行证。档案失败保留本地资料；并发修改以版本号阻止静默覆盖。通行证不是服务器进程内正在进行的对局备份。

直接运行源码时，用环境变量 `SP_PROFILE_DIR` 指定私有存储目录；未配置则关闭此个人版服务。部署工具已经指定 D 盘目录。迁移服务器时连同该目录备份，勿放进 public/。

「下载完整素材」预热当前网址的 HTTP 缓存：本服清单包含的模型、贴图、地图、字体、音频；外观插件额外提供的皮肤不在基础清单。浏览器按网址隔离缓存，换随机域名不能自动共用。新增「保存离线素材包（跨网址复用）」下载 zip 到玩家电脑，换网址后用原有「导入素材包」选择同一 zip，校验后在该网址本地重建缓存，无需重新从公网下载素材。基础包由 `powershell -File scripts/build-offline-assets.ps1` 生成，本机已生成 31,035 个文件、881,853,065 字节的包。素材包被 Git 忽略。服务更新后重新生成，导入仍按内容哈希判断可用文件。

作战统计默认开启，已有浏览器升级时开启一次，此后尊重手动关闭。战斗阶段剑图标位于全屏右侧，自己／观战／联防／Boss 都按每位玩家一列居中显示；窄屏可横向滚动。「当前战斗」累计当前回合普通战斗与联防；「本局累计」包含此前回合。保留总伤害、总治疗、伤害类型、干员伤害、DPS、治疗与 HPS，同名干员合并、召唤物计入所属干员。

队友采样滑条为 0.5／1／2／3／5／10 秒，默认 1 秒。每次向各战场权威端索取当时累计值，收到后直接替换，不播放中间快照、不平滑追赶。自身计数在本地更新；伤害／治疗完整累计，不受采样频率影响。只有面板打开且页面可见才请求，关闭后停止；多人同时请求合并为一次战场采样。常规战斗进度仅在结束时附带最终统计，不向所有人持续广播排行榜。无法及时取得战场新数据时标明等待。服务器接管读取同一采集器，替换原战场快照；不将重放或观战副本重复相加。

## 随机网址自动恢复（2026-10-20）

个人部署通过 SP_BROWSER_ENTRY_FILE 指向只含公开网址的 JSON（origin 为固定入口，random 为当前随机隧道）。部署工具维护 D 盘 .runtime/browser-entry.json，启动随机入口会同时确保固定入口在线。固定网址作为浏览器存储来源；随机网址进入后自动转到该来源，游戏 HTTP、WebSocket 和首次素材传输仍走随机隧道。固定入口直接打开时仍使用固定线路；两条线路共用档案和 Cache Storage。地址栏最终显示固定域名，固定入口必须可访问。

browser-entry.html 负责首次注册与旧身份迁移，bridge-sw.js 代理游戏请求。代理目标只读服主的 /api/browser-entry，不能由网址参数指定任意服务器。CORS 只允许固定来源；CSP 保持远程脚本和 Worker 禁止，仅为配置的传输放开连接（随机隧道 HTTPS/WSS 域名；本地测试限回环）。旧随机来源如果仍有本浏览器的有效身份，通过两分钟有效、一次兑换的临时码迁移；身份密钥不放入网址。统一入口已有身份时保留该身份，如需切换另一旧身份仍可导入通行证。活跃游戏页的身份不会被迁移夺取。

以后同一浏览器打开新的随机网址，无需重复导入身份文件或素材 ZIP。成功完整传输的带哈希素材自动保存，命中时不访问新隧道；完整素材按钮仍可提前预热全部清单，ZIP 可在统一入口导入一次。音频完整响应也能保存并回答 Range。错误、HTML、空体、不完整 Range 不入缓存；缓存失败不阻止游玩。网页、代码、档案 API、战斗状态不存入素材缓存；新旧素材按内容哈希区分。首次迁移不读取旧随机来源的私有缓存，未在统一入口缓存的素材需要首次下载或导入一次。换浏览器/设备、清理或浏览器回收缓存仍需恢复；通行证保留用于备份和换设备。

当前 841 MiB ZIP 是基础素材包，共 31,035 个模型、贴图、地图、字体、音频等文件。基础清单有 210 个干员条目，额外可穿戴皮肤登记为 0，本服没有外观插件。导入 ZIP 不会增加皮肤。皮肤需要服主安装带模型的外观插件，玩家在设置「外观插件」启用，再在「干员调配」选择干员，通过详情的「皮肤」区切换；自选编队的干员详情也有相同区域。没有任何可穿戴皮肤时，上游界面会隐藏该区域。

## AI 时钟与分场作战统计（2026-10-20）

服务器提前算完普通/联防 AI 战斗，按战场时钟释放结果。此前面板读取已计算的最终计数，导致提前显示结算值且看起来不更新。现在为实际伤害/治疗变化保留精确游戏时间点，采样按当前战场时钟二分读取，不提前显示未来结果，也不插值虚构伤害。只保存计数变化，不新增战斗广播；暂停/接管沿用现有战场时钟，最终值和模拟结果不变。

「当前战斗」可选择个人战斗、联防及对应的首领阶段，进入联防自动选中联防，也可回看本回合个人战斗；两场不叠加。「本局累计」继续包含所有阶段。全队列、伤害/治疗、四类伤害、DPS/HPS、采样间隔均保留。
