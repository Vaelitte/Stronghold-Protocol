# Vaelitte 的个人分支

本分支基于上游 v0.3.1。以下差异由仓库使用者明确要求，属于个人使用偏好，不代表官方规则或上游行为。

## 游玩与素材恢复

- 部署干员、装备、召唤物不自动收起商店或缩放镜头；手动操作保留。
- 准备时单击头像直接查看阵地，战斗时单击直接观战；自己的战斗继续在后台运行。观战不提交权威结果，重连先恢复自身模拟再恢复画面。
- 素材传输共享 4 请求队列，45 秒超时；暂时网络错误有界重试。模型并发 3、60 秒超时；失败图片、清单、地图、场景能在网络恢复后重试。
- 完整调配导出含四个自选位 diy，以及原有 ops 潜能／练度。旧文件缺少 diy 时保留；明确空列表可清空；全不可用的非空列表不覆盖。

## 部署与上游更新

personal 保存个人修改，origin 指向 Vaelitte/Stronghold-Protocol，upstream 指向原作者。合并上游并解决冲突后测试、推送、在无对局时重启；勿用整合包覆盖个人分支。未合并上游后续预览版。

本机 D:/Stronghold-protocol/source 为个人版，3001 端口。相邻 Stronghold-Protocol 保留原版素材，个人版通过目录联接共用。程序、依赖、素材、日志、临时文件和专用浏览器资料保存在 D 盘工作目录，不提交 Git。部署启动只使用 Cloudflare 随机网址，HTTP/WebSocket 同源直接连接游戏，无中间恢复页面。停止隧道不重启游戏。历史桥接 worker 仅保留自注销迁移文件，不再代理请求。

## 玩家档案与通行证

SP_PROFILE_DIR 指定服主私有档案目录；本机是 .runtime/private/player-profiles。未配置时关闭此个人服务。GET/PUT /api/profile 通过 Bearer 私密凭据认证，写入采用 revision，档案从不作为静态文件提供。凭据以哈希作为文件名。服务器重启或会话到期仍可恢复相同公开玩家 ID。

调配、持有、自选编队、皮肤选择、对局记录在修改后自动同步。头像内总览、盟约与策略、战斗累计、历史都由记录计算。昵称相同不等于身份相同。服务器不保存正在进行对局的持久存档。

通行证包含私密凭据，勿分享。关闭旧游戏页后在新网址导入可恢复最新服务器档案；同时活跃的身份不能迁移。当前同盟内不能切换身份。尚未备份且旧来源已失效的数据无法仅凭昵称找回。

## 随机网址与本地目录同步（2026-10-20）

首页／设置 → 玩家档案与通行证 → 本地目录同步。桌面 Chrome／Edge 的安全上下文可选择自己的目录；只读写 Stronghold-data 命名空间，断开不删除文件。player.json 包含身份及五组偏好，assets 存带内容哈希的基础素材。每人使用自己的目录。

新目录在登录后自动建立备份；已有目录先验证身份再恢复并刷新。首次可导入原通行证恢复旧身份，再连接空目录。目录句柄存于当前来源的 IndexedDB，权限有效时同一网址刷新自动恢复；新随机域名通常需要用户再次选择同一个目录，不能跨来源静默授权。目录故障不阻止打开游戏。

档案变更后约 700ms 自动写入，成功服务器同步后再次保存；切后台尝试保存。立即同步等待本地档案和当前素材写入，服务器暂不可用时仍保存本地快照。关闭页面瞬间不保证异步写完，因此退出前可手动确认。切换身份先断开目录。

干净快照读取服务器最新档案；未上传快照只有在服务器 revision 等于其基础版本时才上传，或服务器内容已相同则接受。两边均修改时停止恢复并保留文件，不静默覆盖。可保留 player.json 备份后用原通行证选择服务器档案，再用新的空目录继续备份。快照不恢复进行中的战斗。

## 素材目录与 ZIP

local-sync-sw.js 是素材专用 module worker，仅处理同源 GET 的带哈希 assets/fonts/media 路径。先读目录、再读旧导入缓存、最后请求网络。完整成功响应按需自动写目录；错误、空体、HTML、未完成 Range 不保存。音频 assets/media 别名共享内容，支持本地 Range。目录失败回退网络，不缓存网页、代码、档案 API、WebSocket 或战斗状态。

每份素材用 SHA-256 文件名和两位桶目录保存；原路径／MIME／长度放入有长度前缀的容器，原子关闭后可见。更换随机域名不会改变内容键；改变哈希只下载新版。不会因每个新网址再复制一套目录素材。浏览器原有缓存不自动跨来源读取。

将素材包保存到此目录 使用现有 ZIP 的 CRC／文件和模型组哈希验证，只改变存储目标；导入一次，此后新网址重新选目录直接使用。普通导入到当前浏览器 Cache Storage 的功能仍保留；不支持目录 API 时用通行证和 ZIP 手动恢复。下载完整素材在已连接目录时也自动保存。

本机 ZIP 在 source/public/offline-assets.zip，881,853,065 字节（约 841 MiB）、31,035 个模型、贴图、地图、特效、字体及音频文件，由 scripts/build-offline-assets.ps1 生成并被 Git 忽略。基础清单有 210 个干员、0 个额外可穿戴皮肤，本服无外观插件。导入基础包不会增加皮肤；安装提供模型的外观插件后，在设置启用，再在干员调配／自选编队详情的皮肤区切换。无可穿戴皮肤时该区隐藏。

## 全队作战统计

默认开启并保留用户后续关闭选择。剑按钮位于全屏右侧，自己／观战／联防／Boss 的全队各一列，窄屏可滚动。面板只保留「当前战斗／本局累计」两个页签；当前战斗自动跟随个人、联防和首领阶段，不提供阶段切换页签，各场数据不互相叠加。进入新阶段立即采样；本局累计包含所有阶段。保留总伤害、治疗、伤害类型、干员排序、DPS/HPS；召唤物并入所属干员，同名干员合并。

采样滑条 0.5／1／2／3／5／10 秒，默认 1 秒，读取当时准确累计值，跳过中间快照，无平滑追赶。面板关闭或页面不可见停止，多个查看者合并同一战场采样，不持续广播榜单。自身权威端本地更新，观战副本不重复计入。

服务器提前模拟的 AI 按伤害／治疗实际变化时间记录，按可见战场时钟二分读取；不提前显示未来结算值，不插值虚构数据。统计只读，不改变模拟结果、RNG 或 Golden。

## 验证与环境

相关回归覆盖私有档案认证／版本冲突、通行证跨来源恢复、目录原子文件与范围读取、目录保存失败保护、真实浏览器刷新恢复及素材 worker 读写。浏览器测试以真正的 OPFS 目录句柄验证结构化克隆与 worker 文件访问；操作系统目录选择框仍需玩家实际授权。

此前 288 项 Golden 未改变，本次不修改模拟与 fixtures。Windows 全量测试有缺少 python3 和创建普通符号链接权限的环境限制；不把针对性测试称为全量通过。详见各次提交验证记录。
